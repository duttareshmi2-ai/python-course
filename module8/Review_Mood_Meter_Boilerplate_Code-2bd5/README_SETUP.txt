REVIEW MOOD METER: BOILERPLATE (starter) FILES

What is in this folder
- mood_meter_starter.py : your starter code. Fill in every TODO.
- mood_meter_app.py     : the web page for step 8. It uses your finished starter.
- requirements.txt      : the one package you need for the web page (gradio).

Setup
1. You need Python 3.10 or newer.  Check:  python --version   (Windows: py --version)
2. Steps 1 to 7 need nothing to install.
3. For step 8 (the web page) install the package once:
     pip install -r requirements.txt
   or:   pip install gradio

Run
- The starter:   python mood_meter_starter.py     (Windows: py mood_meter_starter.py)
- The web page:  python mood_meter_app.py         then open http://127.0.0.1:7860
Keep all the files in the same folder and run the commands from that folder.
Do not add share=True to the web page: it makes a public link to your computer.
