DID YOU MEAN: BOILERPLATE (starter) FILES

What is in this folder
- did_you_mean_starter.py : your starter code. Fill in every TODO.
- did_you_mean_app.py     : the web page for step 9. It uses your finished starter.
- requirements.txt        : the packages you need for the web page (gradio and a recent jinja2).

Setup
1. You need Python 3.10 or newer.  Check:  python --version   (Windows: py --version)
2. Steps 1 to 8 need nothing to install.
3. For step 9 (the web page) install the packages once:
     pip install -r requirements.txt

Run
- The starter:   python did_you_mean_starter.py     (Windows: py did_you_mean_starter.py)
- The web page:  python did_you_mean_app.py         then open http://127.0.0.1:7860
Keep all the files in the same folder and run the commands from that folder.
Do not add share=True to the web page: it makes a public link to your computer.
